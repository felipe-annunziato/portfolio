# Performance Monitoring Dashboard

## Problem:
In a large bank in Brazil, the management needed a way to monitor the performance of different sales teams and individuals. The existing reporting tools were not centralized or easy to navigate.

## Solution:
I created a set of four dashboards within Salesforce to monitor performance, tailored to different user groups (executives, managers, sales agents). These dashboards helped track:
- Opportunity conversion rates
- Sales goals progress
- Task completion status

The dashboards provided insights that allowed hierarchy levels to monitor performance from the top down, helping to identify bottlenecks in operations, sales tasks, and overall performance. This setup was critical in a bank with over 8 million customers and 5,000 employees nationwide.
